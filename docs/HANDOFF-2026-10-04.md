## 6. Gotchas learned (save yourself the time)
- **Codex on Windows:** see A.2 above. Codex also hits its own usage limits; check `/status`.
- **Claude headless lanes:** `claude -p "<prompt>" --model sonnet|opus --effort high --strict-mcp-config --permission-mode acceptEdits --allowedTools "Read" "Write" "Edit" "Glob" "Grep" "Bash(npm test*)" "Bash(npx tsc*)" "Bash(npx vitest*)"`. For a lane that must call a live service, load `.env` into the *launching* shell so the agent's process has the variables but never reads or prints them.
- **Shell quoting:** nested backslashes in `node -e`/heredocs broke several scripted edits; use the editor tool for multi-line source edits.
- **File symlinks need privileges on this Windows PC; directory junctions do not.** Tests that need a link escape use `fs.symlink(target, link, 'junction')`.
- **Intermittent test flake:** one or two tests (notably in `tests/beaver-organize.test.ts` A5, "locked or in use" skip) occasionally fail under a loaded full-suite run, most likely Windows Defender briefly locking freshly created files. They pass on re-run. Not a logic bug; consider making that rule's test tolerant.
- **`npm ci --ignore-scripts`** avoids Electron's large binary download when you only need typechecking and vitest. After `main` brought in the app shell, run it in any older worktree before `npx tsc`.
- Chanuth's `package.json` now has Electron/React; `npx tsc --noEmit` fails with "Cannot find module 'electron'" in a worktree that has not been reinstalled; that is an install issue, not a code bug.
- Scout's Backboard answer has **no structured citations** (only URLs inside the text): Scout's prompt must ask for links. The Warden Screen assistant answers in a fenced JSON block; confirm the classifier parser handles the fence.
