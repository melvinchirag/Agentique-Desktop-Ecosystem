---------------------------------------------------------------------
 1. ONE-TIME SETUP (~10 min)
---------------------------------------------------------------------

 1. Install Git LFS (stores big .blend files properly):
       git lfs install
 2. Clone the team repo (Chanuth will share the link) and go in:
       git clone <repo-url>
       cd <repo-folder>
 3. Make your branch for Chip's graphics:
       git switch main
       git pull
       git switch -c chip/graphics
       git push -u origin chip/graphics
 4. Tell Git LFS which files are big (only once, the first time):
       git lfs track "*.blend"
       git lfs track "*.fbx"
       git add .gitattributes
       git commit -m "chip(graphics): track blend files with LFS"
       git push
 5. Make sure Blender backup files never get committed. Add this
    line to the .gitignore file:
       *.blend1

 5. YOUR AI HELPERS (ChatGPT + Codex)
---------------------------------------------------------------------

 Use CODEX to write three small Blender Python tools ONCE. They
 check and export every animal automatically, so you never
 export by hand or miss a clip name.

 Model routing (cheapest that's good enough):
   - Codex  GPT-6 Sol  (medium effort)  -> the two Blender scripts (Z2, Z3)
   - Codex  GPT-6 Luna (medium effort)  -> the simple clip-list file (Z1)
   - ChatGPT (chat)                     -> animation and rigging questions
     ("how do I make the tail puff up for Scared?")
   If a script fails twice: raise the effort one step (medium -> high).

 Run Codex like this, in the repo folder. The extra flags stop it
 from touching any of your accounts:
       codex --ignore-user-config --disable apps
   Then paste one task below.

 ---- Z1 (Codex GPT-6 Luna, medium) ---------------------------------
   "Create tools/blender/required_clips.json. For each animal id
    (chipmunk, wolf, workspace, beaver, eagle, ants, butterfly,
    nightingale) list the required animation clip names from
    docs/ASSETS.md section 3 and, for chipmunk, from
    docs/animations/chip-actions.md. Mark each clip as
    'loop': true/false and 'tier': 1-4. Chipmunk does NOT need
    SleepWalk. JSON only, no code."

 ---- Z2 (Codex GPT-6 Sol, medium) ----------------------------------
   "Create tools/blender/check_character.py, a Blender Python script
    run as:
      blender -b art/<animal>/<file>.blend --python tools/blender/check_character.py -- <animal_id>
    It prints a PASS/FAIL report:
    - every required clip from tools/blender/required_clips.json
      exists as an Action with that exact name (case-sensitive),
      and has Fake User on
    - looping clips: first and last keyframes match
    - scene frame rate is 30
    - triangles <= 15000, bones <= 60, max 4 weights per vertex
    - object transforms applied, origin near the feet (z ~ 0)
    - optional shape keys found: MouthOpen, Blink, Smile, Worried
    It changes nothing in the file. Report only."

 ---- Z3 (Codex GPT-6 Sol, medium) ----------------------------------
   "Create tools/blender/export_character.py, a Blender Python script
    run as:
      blender -b art/<animal>/<file>.blend --python tools/blender/export_character.py -- <animal_id>
    It exports the armature + mesh to
      src/renderer/public/characters/<animal_id>/default/model.glb
    with glTF binary, +Y up, apply modifiers, animation mode
    'Actions', always sample animations, include shape keys,
    no cameras or lights. Then it prints the file size and
    fails if it's over 5 MB."

 Commit these tools on chip/graphics:
       git add tools/blender
       git commit -m "chip(graphics): blender check + export tools"
       git push


---------------------------------------------------------------------
 6. YOUR LOOP FOR EVERY ANIMAL
---------------------------------------------------------------------

   1. Model + rig in Blender (save in art/<animal>/).
   2. Animate the next tier of clips (exact names!).
   3. CHECK:  blender -b art/chipmunk/chipmunk.blend --python tools/blender/check_character.py -- chipmunk
      -> fix anything that says FAIL.
   4. EXPORT: blender -b art/chipmunk/chipmunk.blend --python tools/blender/export_character.py -- chipmunk
   5. LOOK at it: when the app exists, use the Asset Lab
      (Ctrl+Shift+A). Until then, drag model.glb into any glTF
      viewer that plays animations, to see every clip move.
   6. SAVE: git add / commit / push (section 4).
   7. Next tier.
